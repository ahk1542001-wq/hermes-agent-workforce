# Video data boundaries

Public: adapted Creator/Voice instructions, original reusable helpers and tests, synthetic configuration examples, upstream notices and links to previously approved showcase videos.

Private: cloning references, authorization/review receipts, credentials/service accounts/OAuth tokens, sessions, browser state, project jobs, personal captures and caches. A public voice demo does not authorize disclosure of its original voice-cloning reference.

The installer creates fresh profile templates and refuses existing destinations. The shared Voice driver binds actual owner authorization and input hashes to each job. No public example grants upload, compute or publishing permission.

The exact release allowlist and boundary scanner reject unexpected files, private paths, credential-like values and prohibited binary/archive documents. Third-party engines and personal artwork are prerequisites, not bundled assets.
