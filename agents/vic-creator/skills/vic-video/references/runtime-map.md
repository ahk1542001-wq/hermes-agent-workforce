# Public runtime map

| Style | Included here | External prerequisite |
|---|---|---|
| UI Motion / Visual Story | `resources/short/scripts`, HTML template, sound/visual contracts | Python/Playwright/Chrome/FFmpeg, local Myanmar font and your own presenter/assets |
| Cartoon Story | narration binding, camera/rig extensions and direction reference | Reviewed AniDoodle Node/TypeScript runtime from https://github.com/alexgreensh/anidoodle |
| Spatial Motion | direction and polish guide | Reviewed KAPE design/helpers, HyperFrames0.8.117 and GSAP3.14.2 |
| Paper Motion | sample-based timing converter and tests | Reviewed https://github.com/alchaincyf/huashu-art-motion Canvas engine |

The installed example uses `/opt/vic/runtimes`; the profile installer resolves this to the runtime root you provide. This release does not download or execute external repositories. Review their source/dependencies/licenses before local installation. No claim is made that latest upstream HEAD is compatible with historical owner jobs. Retain pinned versions in your own environment.

The placeholder presenter manifest intentionally contains no personal avatar. Configure your five PNG poses with the supplied helper before preparing a short job. No external accounts, private job examples or asset rights are inferred from these paths.
